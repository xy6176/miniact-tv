# 使用、安装与常见问题

## 安装

普通Android电视可通过其应用安装器安装Release的APK。使用ADB时先在电视开启调试，在电脑连接，并在电视上允许授权：

```sh
adb connect TV_IP:5555
adb -s TV_IP:5555 install -r MiniAct-1.2.9.2-68.apk
adb -s TV_IP:5555 shell am start -n dev.miniact.nativeapp/com.hgtv.star.MainActivity
```

将`TV_IP`替换为电视地址；新版无线调试的连接端口可能不是5555。`unauthorized`表示电视尚未授权当前电脑，需要电视上确认；配对码方式和传统网络ADB是不同连接流程。

部分TCL固件会对普通安装返回`INSTALL_FAILED_VERIFICATION_FAILURE`。本次TCL通过其“多屏互动”的应用推送确认入口安装成功。该过程需要电视确认“同意”，适用范围取决于固件；不建议通过卸载系统安装器或停用校验组件解决。本资料没有附一键自动安装脚本，也不运行Aerial的完整安装脚本来替代MiniAct安装。

保留应用ID和签名的更新可使用覆盖安装。遇到签名不一致时不要直接卸载以免丢数据，应先确认安装包来源。新安装默认不携带别的应用或别的电视的账号。

## 应用内更新

进入「设置 → 关于 MiniAct → 检查更新」。发现更高版本后，可以在电视上下载并核验 APK，再打开系统安装界面确认覆盖安装。如果系统先要求允许 MiniAct 安装应用，授权后返回下载弹窗，再选择「安装更新」。

更新需要电视能访问 GitHub。已有版本如果没有「检查更新」入口，需要手动覆盖安装一次支持此功能的版本。电视系统无法打开安装器时，可从 GitHub Releases 手动下载安装包。

## 默认遥控逻辑

| 场景 | 上/下 | 左/右 | 确认 | 长按确认/菜单 | 返回 |
| --- | --- | --- | --- | --- | --- |
| 浏览目录 | 移动焦点/滚动 | 栏目与内容间移动 | 打开所选内容 | 按页面提供操作 | 从内容返回侧栏，或按页面逐级返回 |
| 推荐发现 | 上一部/下一部 | 依当前播放器绑定 | 进入当前剧的正式追剧 | 播放选项 | 离开推荐 |
| 正式追剧 | 上一集/下一集 | 快退/快进 | 暂停/继续 | 右侧播放选项 | 从推荐进入时先回推荐，其他入口逐级返回 |
| 播放选项 | 在选项间移动 | 切换分组/按面板提示 | 进入设置或确认 | 不重复触发短按 | 二级页先回列表，再关闭 |

默认绑定可在设置调整，屏幕提示按实际绑定显示。选集在右侧播放面板内展开，选中集数后收起并播放，避免突然移动到画面底部。

## 推荐与横屏优先

默认启动进入精选主页。设置 → 遥控与导航 → 启动页面，可选择精选或推荐视频；一次迁移后尊重用户保存的选择。启动页切换的完整双向重启回归仍待补齐。

综合推荐默认；横屏优先仅改变顺序，保留竖屏及未知画幅内容。关闭优先后会使旧请求与对应快照失效，不沿用旧横屏排序。推荐模式上下换剧，确认进入正式追剧后才按上下切集。

## 长剧选集

在右侧播放面板进入选集。翻页后焦点保留在上一页/下一页按钮，便于连续翻页；按下进入当前页最近一格。范围按钮支持分段浏览，每层最多八项；返回逐级回到原入口。

“跳到集数”支持屏内数字键盘和遥控数字键。输入后先定位浏览焦点，仍需确认具体集数才开始播放；“定位当前集”回到正在播放的位置。自动连播更新当前播放标记，不强制拖动用户正在浏览的页。

## 主题

设置 → 画面与性能 → 外观主题。影院深色默认；酒红丝绒、深海蓝、琥珀棕可选。选择自动保存。若性能或可读性不理想，可开启减少动画、减少透明效果。

## 登录与收藏

进入账号页，按界面选择扫码或手机号登录，自行阅读协议并完成认证。不要把验证码、二维码登录凭据、Cookie或Token发到Issue。

详情页选择“收藏这部剧”，或长按确认打开播放选项后选择收藏。同步中保留状态，确认写入并回读账号收藏后显示成功；失败可重试。进入收藏/账号、回前台会主动核对收藏，浏览相关页面时约每 30 秒核对；实际刷新仍取决于账号与网络状态。它不是无条件即时推送。

## 遇到问题

- 黑屏或有声无画：先确认系统HEVC能力、清晰度和解码设置，软件模式只使用系统已有软件解码器。
- 一直加载：记录设备系统、剧名/集数、清晰度、是否每次发生；网络和上游内容都可能影响，避免把所有等待归因于UI。
- 搜索无结果：保留实际关键词与无匹配提示，可尝试剧名/别名；本客户端不能保证平台搜索覆盖所有作品。
- 收藏不同步：检查账号是否有效、是否仍显示同步中或重试，不以本机按钮变化代替云端成功。
- 页面或遥控异常：附电视型号、系统、复现步骤和已遮盖私人信息的截图，使用本仓库Issue模板反馈。
