# 视觉与交互设计

设计方向受tvOS大屏的内容层次、克制动效与材质启发，落地为Android原生View；没有Apple官方认证或复用其品牌素材。

## 一套状态，而非一圈白框

| 状态 | 表达 |
| --- | --- |
| 普通常态 | 安静的深色或对应主题底面 |
| 当前栏目/当前集/已选值 | 短标记、播放标记或勾选 |
| 遥控焦点 | 暖白面与深色文字，或图片轮廓强调 |
| 同步中/失败 | 明确文字反馈与重试，不冒充已完成 |

焦点不改变控件几何尺寸，不逐项改变字体字重。导航图标固定一列，文字在独立区域居中。选择状态和焦点不能用相同高亮混淆。

## 页面层次

精选大图用真实封面和渐隐遮罩；优先横封面，缺失时等比裁切竖封面，不把裁切图称作官方横版剧照。继续观看保持竖海报比例，文字与进度在下方。长标题允许两行并给操作区留独立空间。

浏览栏目共用当前主题场景；详情和播放分别持有剧目环境，返回恢复浏览环境，避免看过详情后主页被染色。选集和播放设置都属于右侧面板的分级任务，不能跳到另一个方位。

## 主题与材质

影院深色默认，酒红丝绒、深海蓝、琥珀棕可选。背景、玻璃、按钮底色一起切换，保留相同的焦点语义。低亮底色、宽幅柔光、细边高光分工，减少整页均匀灰罩。

玻璃使用192×108共享纹理，封面改变时才处理；不抓取窗口，不实时模糊视频，不要求Android12的RenderEffect。四主题光照缓存合计约0.32MB。减少透明效果用主题实色回退。详细参数和旧设计演进见[原始设计记录](../../MINIACT_DESIGN.md)。

## 实现入口

共享参数MiniActTokens；主题MiniActTheme；背景与光照MiniActDesign/MiniActAtmosphere；玻璃MiniActGlass；普通操作MiniActControlSurface；海报MiniActPosterTile；首页MiniActHomeFeed。修改同类控件时优先修改共享角色，避免每页独立造一套焦点与玻璃。
