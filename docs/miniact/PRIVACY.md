# 数据与隐私说明

这是基于当前源码的行为说明，不代替内容平台自身的隐私政策。

| 数据 | 当前用途与存储 |
| --- | --- |
| 登录Cookie/Token、设备档案 | 用于平台认证及账号请求，保存在本应用私有存储；不随APK或源码分发 |
| 本机历史、进度、偏好 | 支撑续播、片单与外观设置 |
| 账号收藏 | 登录后向内容平台读写；服务器回读确认后显示同步完成 |
| 图片/媒体缓存 | 减少重复请求和起播等待，受缓存策略管理 |
| 手机输入 | 由已有本机输入流程完成；具体连接提示以应用界面为准 |

当前`SessionMirror.dirs()`仅返回应用私有files目录，不使用HGTV公共会话镜像。会话文件是私有目录中的明文存储，不能宣传成端到端加密或专门的硬件密钥保护。卸载、清数据或设备迁移可能丢失本机数据；账号收藏与本机备份不是同一种恢复机制。

登录与内容请求会访问相应内容平台；本项目不是完全离线应用。项目未新增MiniAct自建统计服务。继承的诊断能力及工具可能产生敏感日志，反馈前应自行检查和遮盖。

不要上传：手机号/验证码、登录二维码、Cookie/Token、会话备份、设备档案、签名私钥、完整网络抓包或未经检查的设备日志。Issue模板不要求这些信息。历史登录研究工具不包含在本次公开仓库中，也不是运行客户端的必要步骤。
