# 产品演进与交接

## 路线

早期MiniAct使用网页基座，遇到双控制栏、网页闪现、起播等待、权限与Web状态割裂。随后探索过独立原生验证方案，最终采用HGTV原生工程作为基础。网页时期的方案与安装包不属于本次现行工程，避免混发。

现行路线是在上游原生能力之上建立MiniAct自己的电视产品体验。目标从“能播”扩展到“发现、追剧、续播、收藏、设置、退出都连贯”，同时保留可追溯的验证证据。

## 关键问题与已采用方案

| 曾出现的问题 | 当前处理思路 | 维护时避免回退 |
| --- | --- | --- |
| 进入分类后回不到导航 | 固定侧栏、返回聚焦导航、保存内容焦点 | 页面重绘后丢失栏目/焦点 |
| 推荐和正式播放按键冲突 | 上下换剧与上下切集按模式分开 | 旧请求完成后切错剧或误进入追剧 |
| 播放设置和选集位置割裂 | 右侧面板内二级选集，逐级返回 | 重用整宽底部面板覆盖电视模式 |
| 普通/选中/焦点一样亮 | 暖白表示焦点，当前项用独立标记 | 大面积白框和多处同时亮面 |
| 首页向下滚动长帧 | 双层列表回收、图片回填节流、缓存绘制 | 每次焦点变化重建整页或实时模糊 |
| 长标题挤掉按钮 | 根据实际文字高度留操作区 | 固定字符数代替实际排版测量 |
| 竖封面硬塞横卡 | 继续观看竖海报与下置进度 | 把竖视频拉伸成横版 |
| 详情背景污染首页 | 浏览/详情/播放场景隔离 | 共享可变全局海报背景 |
| 横屏优先关闭后仍只有横屏 | 推荐请求代次与快照按偏好隔离 | 关闭开关却复用旧队列 |
| 收藏本机成功但账号没成功 | 固定会话、写入及回读确认、失败重试 | 乐观更新冒充云同步成功 |
| 视觉只改背景色不改控件 | 主题统一驱动背景、玻璃与底面 | 给不同页面添加孤立配色 |

## 后续接手顺序

先读README、USER_GUIDE、COMPATIBILITY，再读ARCHITECTURE、DESIGN与BUILD。改功能前确认目标属于推荐发现还是正式追剧；改视觉时定位共享控件；改账号时梳理会话身份与异步回调。小范围验证通过后再扩展，保留失败事实和测试条件，不以“未见崩溃”代替功能完成。

更细的逐轮记录见根目录MINIACT.md。它按时间保存历史，不是当前功能清单。
