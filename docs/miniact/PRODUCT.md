# 产品说明与价值

## 定位

MiniAct是支持横版视频推荐的第三方红果短剧TV客户端。横屏优先推荐是主要展示优势，遥控追剧、长剧选集与收藏续播构成完整观看路径。副标语为“小剧集，大屏看”。应用内无广告，简短说明即可。

## 典型任务

| 用户想做什么 | 提供的路径 | 实现边界 |
| --- | --- | --- |
| 不知道看什么 | 默认精选主页；可将推荐视频设为启动页，上下换剧 | 由平台返回推荐，不声称自建个性化算法 |
| 找到一部后继续追 | 确认进入正式播放，上下切集，保留进度 | 默认按键可在设置更改 |
| 用大屏看横版内容 | 开启横屏优先排序 | 保留竖屏和未知画幅，不等于“仅横屏” |
| 继续上次看的内容 | 继续观看栏目、竖版海报和进度 | 本地历史与平台账号能力分别处理 |
| 找续作与同类 | 相关剧集、作者作品、季号识别 | 关联结果依赖平台元数据，不能保证所有同名作品都是同系列 |
| 记住喜欢的剧 | 详情/播放内收藏、片单查看 | 需有效登录；服务器回读确认后显示同步完成 |
| 遥控输入中文 | 搜索联想、历史、手机输入、准确剧名优先 | 上游搜索仍可能无匹配或慢响应 |
| 更换观看氛围 | 四主题，保留焦点及按键语义 | 主题只改变视觉，不替换内容源 |

## 与上游的关系

HGTV提供原生客户端、内容协议、登录与播放基础。MiniAct围绕固定导航、内容首页、推荐追剧双模式、共享材质、搜索输入路径和账号收藏确认做了派生修改。应把这些明确描述为MiniAct的贡献，避免把继承的取流与解码实现归为全新开发。

## 对外可以使用的表述

“为遥控器设计”“原生播放”“四种主题”“推荐发现与正式追剧分开”“详情与播放内账号收藏”“考虑低配设备的缓存与效果策略”。

不使用“苹果官方设计认证”“网飞同款”“所有电视通用”“永久免费全集解锁”“任意片源秒播”“永不掉帧”等没有证据或无法控制的表述。具体成绩放在带设备、日期和条件的验证记录中。
