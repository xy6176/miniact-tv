# 后续计划与待验证项

本文件是建议优先级，不表示这些能力已经完成或有确定交付日期。

| 优先级 | 工作 | 验收方式 |
| --- | --- | --- |
| P0 | 全局焦点、长剧末页与TCL完整播放回归 | 冷启动、指定集、上下集、连播、暂停恢复、末集与导航往返 |
| P0 | 1–2GB与不同芯片设备覆盖 | 实测内存、解码能力、全页滚动和长时间播放，区分冷/热缓存 |
| P0 | 建立MiniAct独立发布与签名流程 | 版本、签名连续性、对应源码、校验和、Release产物逐一核对 |
| P1 | Android旧/新系统矩阵 | 安装、联网、登录、播放、后台恢复、遥控器差异 |
| P1 | 最终主题版重新量化滚动 | 固定路线、相同缓存条件、长帧与p95，不复用旧测量作新成绩 |
| P1 | 登录与网络失败状态 | 过期、刷新、断网恢复、取消、重试及换号并发，用户自行认证 |
| P1 | 相关剧集准确度 | 同名不同剧、续季、别名、作者作品缺失与空结果 |
| P2 | 清理历史注释与研究文档 | 对照当前私有存储和品牌，减少“旧方案看起来仍在使用”的误导 |
| P2 | 可访问性与大字号矩阵 | 焦点说明、长标题、1.3及更大字号、低对比显示环境 |

已处理过的问题及经验见[产品演进与交接](EVOLUTION.md)。
